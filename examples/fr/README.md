# Profils d'exemple

Plannings **fictifs**, pour essayer AgendApp sans saisir sa propre organisation. Les noms sont inventés.

Dans l'app : **Réglages › Sauvegarde et restauration › Restaurer depuis un fichier**, puis choisis un
fichier. Tes données actuelles sont remplacées (tu peux annuler juste après, ou faire une sauvegarde avant).

| Fichier | Profil | Contenu |
|---|---|---|
| [nursing-12h.json](nursing-12h.json) | Infirmier·e en 12 h (jour / nuit) | 4 types, 1 règle(s), 70 événements |
| [factory-3x8.json](factory-3x8.json) | Équipe postée en 3×8 | 3 types, 0 règle(s), 70 événements |
| [firefighters-24h.json](firefighters-24h.json) | Sapeur-pompier : gardes de 24 h | 4 types, 1 règle(s), 53 événements |
| [patrol.json](patrol.json) | Patrouilles (sécurité, police, armée…) | 4 types, 2 règle(s), 60 événements |
| [transit.json](transit.json) | Conducteur de bus ou de tram (services coupés) | 3 types, 1 règle(s), 94 événements |
| [shared-custody.json](shared-custody.json) | Garde alternée et activités | 2 types, 0 règle(s), 25 événements |

Générés le 2026-10-11 par `web/scripts/examples.mjs` (`npm run examples` pour les régénérer autour d'une autre date).
